# Кейс 3 «Синаптик»

Основной документ для сдачи — `Отчёт_Синаптик.pdf`. В нём приведены пять гипотез, расчёты, предложения по проверке и ограничения данных. `Текст отчёта.md` содержит тот же материал в редактируемом виде. В папке `расчёты` находятся программы и сохранённые агрегированные результаты в `results`.

## Повторение расчётов

Исходные выгрузки и журналы в комплект не включены: они содержат чувствительные данные. Их можно получить из [публичной папки владельца](https://disk.yandex.ru/d/UYuFNCrHvWR3DQ). Для воспроизведения нужны те же версии файлов, что использовались 28 октября 2026 года; хеши входных файлов записаны в результатах. Доступность и неизменность выгрузки не гарантируются.

Создайте папку `расчёты/data` и поместите в неё `users.csv`, `devices.csv`, `device_code.csv`, `orders.csv`, `subscribe.csv`, `product.csv`, `product_trial.csv`, `metric_values.csv`, `logs.zip`, а также схемы `orders_schema.csv` и `subscribe_schema.csv` из `db_structure`. Файлы CSV должны оставаться без строк заголовков, как в исходной выгрузке. Не публикуйте эту папку.

Нужен Python 3.11 или новее; сторонние библиотеки не требуются. Из папки `расчёты` выполните:

```sh
python3 analyze.py
python3 extended.py
python3 analyze_logs.py
python3 traffic_logs.py
```

Скрипты перезапишут файлы результатов в `results`. Обработка журналов может занять продолжительное время и требует свободного места для временных файлов. При изменении исходных данных показатели могут отличаться; архивы логов отобраны по инцидентам и не представляют все сеансы пользователей.
