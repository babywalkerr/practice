# Кейс 2 «ЭЛМА»

Епифанов Максим Дмитриевич, группа 23-05-06-00.

- `Отчёт_Епифанов_кейс_2.pdf` — отчёт, схема процесса и таблицы.
- `variants.csv` — полные маршруты и доли заявок.
- `student_transitions.csv` — наблюдаемые пары соседних активностей.
- `students.csv` — исходный синтетический журнал, необходимый для воспроизведения расчётов; по описанию данных он не содержит реальных пользователей и документов.
- `analyze.py` — код анализа и проверок.

Для повторного расчёта установите Python 3 и запустите в этой папке `python3 analyze.py`. Дополнительные библиотеки не нужны. Скрипт проверит структуру журнала, выведет сводку и перезапишет `variants.csv` и `student_transitions.csv`. Для Excel импортируйте CSV через «Данные → Из текста/CSV»: UTF-8, разделитель — запятая.

Схема отражает наблюдаемые переходы; внутреннее устройство процесса по журналу не устанавливается. Данные учебные и синтетические.
