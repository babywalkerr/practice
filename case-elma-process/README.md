# Кейс 2: восстановление процесса

- `Схема.md` — схема Mermaid и легенда (отображается в просмотрщике с поддержкой Mermaid).
- `Отчёт.md` — метод, результаты, примеры и ограничения.
- `variants.csv` — полные варианты; `student_transitions.csv` — наблюдаемые пары.
- `students.csv` — копия исходного синтетического журнала; `analyze.py` — воспроизводимый анализ.

Запуск из любой директории: `python3 /путь/к/case-elma-process/analyze.py`. Нужен Python 3, установка пакетов не требуется. Скрипт проверяет структуру журнала, выводит сводку и перезаписывает оба CSV результата. `variants.csv` записан в UTF-8 с BOM для Excel, переходы — в UTF-8. Импорт CSV в Excel: «Данные → Из текста/CSV», UTF-8, разделитель запятая; UUID хранить как текст.

`Отчёт_Епифанов_кейс_2.pdf` объединяет отчёт, схему и таблицы. Для повторной сборки PDF: `python3 make_report.py` в папке кейса; нужны библиотека `reportlab` и шрифты Arial из `/System/Library/Fonts/Supplemental` (macOS). Сначала при необходимости запустите `analyze.py`, чтобы обновить таблицу вариантов.
