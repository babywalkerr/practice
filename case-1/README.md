# Кейс 1 ЭЛМА: состав и воспроизведение

- `Отчёт.pdf` — краткий отчёт с выводами и ограничениями.
- `anomalies.csv` — перечень потенциальных отклонений.
- `students.csv` — исходная учебная синтетическая выгрузка; необходима для воспроизведения.
- `analyze.py` — код анализа.

Для запуска необходимы Python 3 и pandas. При необходимости установите pandas командой `python3 -m pip install pandas`. Из этой папки выполните `python3 analyze.py`. Скрипт перезапишет `anomalies.csv` и создаст `duration_stats.csv` и `summary.json` с дополнительной статистикой. Даты учитываются с часовым поясом; анализ ограничен срезом 01.07.2026 00:00 UTC+03:00. В исходной выгрузке есть 25 событий после среза; они исключаются, как объяснено в отчёте.
